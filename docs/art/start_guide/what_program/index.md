# 픽셀 아트에 사용할 프로그램/앱 가이드

## 가장 많이 사용되는 프로그램

Q. 어떤 프로그램을 가장 많이 쓰나요?  
**A. Aseprite**

### 그동안 가장 많이 사용되었던 프로그램: **어도비 포토샵**  

- **장점**  
  - 플러그인 확장을 통한 자유로운 작업 환경
  - 수많은 자동화 도구
  - 원래 업계에서 사용하던 만큼 수많은 자료 및 협업 용이

<br>

- **단점**
  - 비쌈
  - **픽셀 아트라면 굳이 없어도 된다**  
\>> 대량 작업 및 협업에 용이할 뿐이지 낮은 해상도의 픽셀 아트 자체는 단순한 비트맵 편집/드로잉 툴이면 대부분 무리 없이 가능하다
  - 애니메이팅 작업을 직접 보면서 할 수 있는 환경 구성이 힘듦

<br>

### 지금 가장 많이 사용되는 프로그램: **Aseprite**

인디게임들을 중심으로 아트/게임 작업 할것 없이 가장 널리 사용되는 프로그램

- **장점**  
  - 넓은 커뮤니티 덕에 있는 수많은 자료와 도구 및 협업 용이
  - 태그 기능을 통한 **원활한 셀 애니메이션 작업**
  - 게임 스프라이트 작업 기준 타일링 전용 도구, json 내보내기 등등 편리한 여러 지원
  - [직접 패키징](/art/ase_install)시 무료로 사용 가능

<br>

- **단점**
  - **인디 도구인 만큼 어딘가 불안정한 프로그램**
    - 자주 잘못 눌리는 도구 전환
    - 확대 배율 제한 및 축소 시 이미지 심하게 뭉개짐
    - 도구 창 이동 제한
    - UI의 유니 폰트 해상도 깨짐
    - 업계 표준과 다른 제스처 및 단축키
  - 안드로이드 / iOS, iPadOS 미지원

## Aseprite의 대체 프로그램

### EDGE3

> [다운로드](/art/pixelart_program/index.md/#edge3)

- **장점: 완전히 현대적인 디자인 툴의 UI**  
  - 깨지거나 어색하게 움직이는 UI 없음
  - 안 깨지는 UI의 유니 폰트
  - 업계에서 사용되는 제스처/단축키
  - 자유롭게 움직일 수 있는 창
  - 확대 배율 제한 및 축소 시 이미지 뭉개짐 없음

<br>

- **단점**
  - **얼리억세스**
    - 플러그인, 오토 타일링은 나중에 지원 예정
    - 단, 피드백을 넣을 시 반영이 매우 잘 되는 편
  - 한국 스팀 기준 21,000원으로 싼 편은 아님

## 폰, 태블릿에서 픽셀 아트를 하고 싶을 경우

- **아이패드에서 취미로 작업**  
\> [Pixquare](/art/pixelart_program/index.md/#pixquare)  
필요한 요소를 갖추고 있어서 간결한 UI가 특징
- **태블릿에서 여러 기능을 활용한 작업**
\> [Resprite](/art/pixelart_program/index.md/#resprite)  
비파괴 레이어, 클리핑 마스크, 유사 키프레임 애니메이션등 매우 다양한 기능 지원
    > PC 버전은 비추천
- **애니메이션 없이 간단한 낙서 / 모바일로 사용**  
\> [Ibis Paint](/art/start_guide/ibispaint_pixelart/index.md)
  - 잘돼있는 모바일 UI
  - 가격 무료
  - 저사양에서도 잘 돌아감
  - 드로잉 앱이라 기본적인 필요한 도구는 제대로 갖춤
